# Contribuindo

Leia README.md e AGENTS.md. Abra uma issue com versão do programa, distribuição, modelo, conexão usada e erro reproduzível. Remova dados pessoais dos diagnósticos.

Para desenvolvimento, crie um ambiente virtual, instale PySide6-Essentials e execute `QT_QPA_PLATFORM=offscreen python -m unittest discover -v`.

Envie PRs pequenos com problema, solução e resultados dos testes. Mudanças de protocolo exigem evidências e indicação dos testes físicos realizados; simuladores não substituem confirmação no dispositivo. Não envie logs pessoais, instaladores ou recursos proprietários.
