# Imagens opcionais do usuário

O programa funciona sem arquivos de imagem do fabricante: desenha uma ilustração genérica original com Qt.

Usuários da versão local anterior podem copiar `x11-398.png` e `led-masks.json` de seus próprios recursos para esta pasta para preservar a imagem e a prévia do LED. Não são necessários para consultar ou configurar o mouse. Não são baixados automaticamente. Esses arquivos são ignorados pelo git e não devem ser incluídos em PRs ou releases sem autorização de redistribuição.
